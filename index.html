How each step works

  • All parameters start high (0.75–1.0), so early on everything changes and switches fast.
  • FT filters neighbor signals: a neighbor only counts if its activity is above 0.6 × FT. Signal that gets filtered out pushes FT down.
  • SG scales the incoming signal; a mismatch between what the cell expected and got pushes SG down.
  • TI sets integration speed: lower TI means faster integration. Leftover lag pushes TI down.
  • UE damps everything: the size of every parameter change and the slot-switching rate both scale with UE. Fast changing wears UE down, so it slows over time.
  • Strategies live on slots. Each parameter receives its own data channel, and that data shapes the strategy of whatever slot it sits in. The strategy then biases the next parameter to move into that slot. Uncheck "Strategy stays on slot" to make strategies follow the parameter instead, as a comparison.
  • Activity follows a smoothed Game of Life rule on the counted signal. An extreme event resets a patch to high parameters and scrambles its activity.
